# Анализ маркетплейса: PMF, метрики и дизайн A/B-теста

Бразильский маркетплейс Olist, 2016-2018. EDA → когортный retention → оценка PMF → ICE → дизайн A/B-теста

---

## Что внутри

- EDA
- Когортный анализ, retention
- Оценка PMF
- 5 продуктовых метрик
- Приоритизация 3 гипотез через ICE
- Дизайн A/B-теста: целевые, прокси и guardrail метрики, MDE, размер выборки

---

## Ключевой вывод

Месячный объём продаж растет за счет агрессивного привлечения новой аудитории, при этом возвращаемость после первой покупки остается на уровне 0,36% (медианный M1 retention)
